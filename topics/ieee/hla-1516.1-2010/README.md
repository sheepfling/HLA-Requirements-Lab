# IEEE HLA 1516.1-2010 reconstruction

This is the source-only faithful reconstruction input for IEEE Std 1516.1-2010
Federate Interface Specification. Accepted native TikZ figures and the
declared FDD/MIM companion source are retained because they are build-critical
text inputs. PDFs, PNGs, audit reports, verifier scripts, logs, checksums, and
withdrawn figure drafts remain outside the tracked document root.

Build it with:

```powershell
hla-lab publish hla-unofficial-faithful-reconstruction-2010
```

The semantic model, requirements traceability publication, and hierarchy-first
2010 document will be generated from validated edition-qualified records. This
source tree is not itself the semantic source of truth, and no 2010-to-2025
equivalence is inferred from the handoff.
