# Supplied prototype reference

This directory preserves the supplied visual prototype and its source studies
for traceability. The production Requirements Lab layer does not load these
files directly: `style/rl-graphics.sty` is the adapted, namespaced family
graphic layer, while `class/requirements-lab.cls` and the shared style files
own production typography, furniture, tables, and front matter.

The prototype establishes the visual contract used by the modern interior:

- Noto Serif prose, sans-serif navigation, and DejaVu Sans Mono technical tokens;
- a short orange rule as the non-semantic family marker;
- restrained one-line headers and visible folios;
- inline table labels, pale blue-gray header bands, and horizontal rules;
- true landscape page media so furniture remains horizontal;
- contained 2010 geometry and layered/extensible 2025 geometry;
- distinct framework, federate-interface, and OMT family glyphs.

The original source studies retain their design-study identifiers so the
reference remains comparable to the supplied prototype. Production documents
use the neutral Requirements Lab publication identity.
