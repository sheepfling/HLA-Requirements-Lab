\vspace{7.9pt}
This standard is the capstone document for a family of related standards that together describe a unified\linebreak
approach to constructing interoperable simulation systems.\par

\vspace{10.0pt}
The High Level Architecture (HLA) provides a general framework within which simulation developers can\linebreak
structure and describe their simulation applications. Flexibility is the aim of the HLA. In particular, the HLA\linebreak
addresses two key issues: promoting interoperability between simulations and aiding the reuse of models in\linebreak
different contexts. Three main components are described within the set of products forming the HLA. The\linebreak
first component, the HLA Framework and Rules Specification (i.e., this standard), provides a set of ten rules\linebreak
that together ensure the proper interaction of federates in a federation and define the responsibilities of\linebreak
federates and federations. The second component, the object model template (OMT), is a necessary basis for\linebreak
reuse and forms a documentation standard describing the data used by a particular model. The third\linebreak
component, the federate interface specification, addresses interoperability and describes a generic\linebreak
communications interface that allows simulation models to be connected and coordinated. Although the\linebreak
HLA is an architecture, not software, use of runtime infrastructure (RTI) software is required to support\linebreak
operations of a federation execution. The RTI software provides a set of services, as defined by the federate\linebreak
interface specification, used by federates to coordinate operations and data exchange during a runtime\linebreak
execution.\par

\vspace{10.0pt}
Simulations are necessarily abstractions of the real world, and no one simulation design can meet the\linebreak
functional needs of the entire modeling and simulation community. However, in defining an overriding\linebreak
architecture, generic issues can be addressed. When doing so, it is essential that such an architecture\linebreak
encompass both differing computing environments and differing classes of simulations.\par

\vspace{10.0pt}
This standard, describing the framework and rules, is intended to provide some of the general philosophy\linebreak
behind the HLA, including guidance about how to design, use, and adhere to the HLA vision.\par
