# IEEE HLA 1516-2010 reconstruction

This is the first ingested 2010-edition source-faithful reconstruction tranche.
It contains the live LaTeX/TikZ source for IEEE Std 1516-2010 Framework and
Rules. The supplied reference PDF, QA reports, source maps, and other
comparison material remain outside the tracked document root.

Build it with:

```powershell
hla-lab publish hla-unofficial-faithful-reconstruction-2010
```

The source is retained as a faithful reconstruction input. Its semantic model
and edition-lineage relations will be added after the 2010 corpus is parsed and
reviewed; no 2010-to-2025 equivalence is inferred from this source handoff.
