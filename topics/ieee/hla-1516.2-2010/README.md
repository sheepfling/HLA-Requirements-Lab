# IEEE HLA 1516.2-2010 reconstruction

This is the first ingested 2010-edition source-faithful reconstruction tranche
for the Object Model Template specification. It contains live LaTeX/TikZ
source for the reconstructed standard body through Annex H. The current
repository XeLaTeX fallback renders 116 pages; the handoff's 110-page count
depends on its unavailable newtx font environment. Supplied PDFs,
audits, source maps, and comparison material remain outside the tracked
document root.

Build it with:

```powershell
hla-lab publish hla-unofficial-faithful-reconstruction-2010
```

The source is retained as a faithful reconstruction input. Its semantic model
and edition-lineage relations will be added after the 2010 corpus is parsed and
reviewed; no 2010-to-2025 equivalence is inferred from this source handoff.
