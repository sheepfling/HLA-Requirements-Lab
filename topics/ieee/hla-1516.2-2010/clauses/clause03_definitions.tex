\subsubsection{Names}
Names in object models shall adhere to eXtensible Markup Language (XML) naming conventions. XML conventions state that names cannot begin with a number or punctuation character, and require that names be constructed from a combination of letters, digits, hyphens, colons, full stops (periods), and underscores with no spaces or other breaking characters (e.g., tabs, carriage returns). In HLA object models, allowable names shall be further restricted as follows:

\begin{enumerate}[label=\alph*)]
\item The period (full stop) is reserved for qualifying class names and shall not be included in a user-defined name within an object model. When fully qualified, the class name includes all predecessor class names (separated by periods) beginning at the root and ending at the class name in question.
\item As recommended in the XML specification, the colon character shall not be used.
\item Names beginning with the string ``hla,'' or any string that would match (('H'\textbar{}'h') ('L'\textbar{}'l') ('A'\textbar{}'a')), are reserved and shall not be included in user-defined names.
\item The case of all textual data within HLA object models (including names) shall be significant; all textual data defined in an object model document shall be case-sensitive.
\item A name consisting of the string ``na,'' or any string that would match (('N'\textbar{}'n') ('A'\textbar{}'a')), is reserved to indicate that a name is not applicable in this circumstance and shall not be included as a user-defined name.
\end{enumerate}

These rules apply to the following names in HLA object models:

\begin{itemize}
    \item Object class names
    \item Interaction class names
    \item Attribute names
    \item Parameter names
    \item Datatype names
    \item Enumerated datatype enumerators
    \item Fixed record field names
    \item Variant record alternative names
    \item Basic data representation names
    \item Dimension names
    \item Transportation type names
    \item Synchronization point labels
    \item Note identifying labels
\end{itemize}
