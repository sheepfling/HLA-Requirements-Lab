3. Definitions, acronyms, and abbreviations\par}
\vspace{20.46pt}

{\HLAFacSans\bfseries\fontsize{10.98pt}{13.18pt}\selectfont
3.1 Definitions\par}
\vspace{8.42pt}

For the purposes of this document, the following terms \textit{and definitions apply. The IEEE Standards Dictionary Online} should be consulted for terms not defined in this clause.\footnotemark[12]\par

\begin{hladefinition}{def-accuracy}{accuracy}
The measure of the maximum deviation of an attribute or a parameter value in the simulation or federation from reality or some other chosen standard or referent.
\end{hladefinition}

\begin{hladefinition}{def-active-subscription}{active subscription}
A request to the runtime infrastructure (RTI) for the kinds of data (class attributes as well as interactions) that the joined federate is currently interested in receiving. The RTI uses these data along with publication data received from other joined federates to support services, such as:
\begin{hladefinitionlist}
\item \HLAService{Start/Stop Registration}
\item \HLAService{Turn On/Off Updates}
\item \HLAService{Turn On/Off Interactions}
\end{hladefinitionlist}
The RTI also uses the subscription (and publication) data to determine how to route data to the joined federates that require that data.
\end{hladefinition}

\begin{hladefinition}{def-attribute}{attribute}
A named characteristic of an object class or object instance. \HLASeeAlso{\HLATermReference{class attribute}\HLASemicolon{} \HLATermReference{instance attribute}.}
\end{hladefinition}

\begin{hladefinition}{def-attribute-ownership}{attribute ownership}
The property of an instance attribute that gives a joined federate the capability to supply values for that instance attribute to its federation execution. \HLASeeAlso{\HLATermReference{instance attribute}.}
\end{hladefinition}

\begin{hladefinition}{def-authorizer}{authorizer}
An interface used to determine if a specific set of service invocations (\HLAService{Connect}, \HLAService{Create Federation Execution}, \HLAService{Destroy Federation Execution}, and \HLAService{Join Federation Execution}) are allowed for the federate, given its credentials.
\end{hladefinition}

\begin{hladefinition}{def-available-attributes}{available attributes}
The set of declared attributes of an object class in union with the set of inherited attributes of that object class.
\end{hladefinition}

\begin{hladefinition}{def-available-dimensions}{available dimensions}
\begin{hladefinitionlist}
\item Pertaining to an object class: the dimensions associated with that object class in union with the set of inherited dimensions in the federation object model (FOM).
\item Pertaining to an attribute: The available dimensions of an instance attribute are the available dimensions of the known class. When registering, subscribing, unsubscribing, requesting updates with regions, or getting available dimensions, the available dimensions are the available dimensions of the object class specified in the service invocation.
\item Pertaining to an interaction class: the dimensions associated with that interaction class in union with the set of inherited dimensions in the FOM. The available dimensions of a sent interaction are the available dimensions of the interaction class specified in the \HLAService{Send Interaction With Regions} service invocation.
\end{hladefinitionlist}
\HLADefinitionNote{See 9.1 in IEEE Std 1516.1\HLAStandardMark-2025.}
\par\addvspace{9.96pt}See dimension.
\end{hladefinition}
