\begin{hladefinition}[0pt]{def-sent-class}{sent class}
The interaction class that was an argument to the \HLAService{Send Interaction}, \HLAService{Send Interaction With Regions}, or \HLAService{Send Directed Interaction} service invocation that initiated the sending of a given interaction.
\HLADefinitionNote[11.58pt]{See 5.1.3 of IEEE Std 1516.1\HLAStandardMark-2025.}
\end{hladefinition}

\begin{hladefinition}{def-sent-interaction}{sent interaction}
A specific interaction that is transmitted by a joined federate via the \HLAService{Send Interaction}, \HLAService{Send Interaction With Regions}, or \HLAService{Send Directed Interaction} service and received by other joined federates in the federation execution via the \HLAService{Receive Interaction} \HLAPrintersDagger{} or \HLAService{Receive Directed Interaction} \HLAPrintersDagger{} service.
\end{hladefinition}

\begin{hladefinition}{def-sent-parameters}{sent parameters}
The parameters that were arguments to the \HLAService{Send Interaction}, \HLAService{Send Interaction With Regions}, or \HLAService{Send Directed Interaction} service invocation for a given interaction.
\HLADefinitionNote[11.58pt]{See 5.1.3 of IEEE Std 1516.1\HLAStandardMark-2025.}
\end{hladefinition}

\begin{hladefinition}{def-set}{set}
A group of elements in which each element occurs at most once (this definition corresponds to the mathematical notion of sets). An example of a set would be a group of class attributes, each of which belongs to the same object class.
\end{hladefinition}

\begin{hladefinition}{def-simulation-object-model-som}{simulation object model (SOM)}
A specification of the types of information that an individual federate could provide to High Level Architecture (HLA) federations as well as the information that an individual federate can receive from other federates in HLA federations. The SOM is specified using one or more SOM modules. The standard format in which SOMs are expressed facilitates the determination of the suitability of federates for participation in a federation.
\end{hladefinition}

\begin{hladefinition}{def-simulation-object-model-som-module}{simulation object model (SOM) module}
A subset of the SOM that contains some or all object model template (OMT) tables. SOM modules and one optional Management Object Model (MOM) and Initialization Module (MIM) are used to specify the SOM of a federate. A SOM module contains complete or scaffolding definitions for all object classes and interaction classes that are superclasses of object classes and interaction classes in the same SOM module.
\end{hladefinition}

\begin{hladefinition}{def-specified-dimensions}{specified dimensions}
The dimensions that are explicitly provided when the region specification is created or modified.
\HLADefinitionNote[11.58pt]{See 9.1.2 of IEEE Std 1516.1\HLAStandardMark-2025.}
\end{hladefinition}

\begin{hladefinition}{def-stop-publishing}{stop publishing}
To take action that results in a class attribute that had been a published attribute of a class no longer being a published attribute of that class.
\end{hladefinition}

\begin{hladefinition}{def-subclass}{subclass}
A class that adds additional detail to (specializes) another more generic class (superclass). A subclass, by inheriting the properties from its parent class (closest superclass), also inherits the properties of all superclasses of its parent as well.
\end{hladefinition}

\begin{hladefinition}{def-subscribe}{subscribe}
To announce to a federation the information a federate wants from the federation.
\end{hladefinition}
