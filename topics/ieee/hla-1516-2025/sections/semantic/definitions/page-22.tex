\begin{hladefinition}[0pt]{def-logical-time}{logical time}
The representation of discrete points on the time axis. Logical time is used to represent a federate's time position and the timestamps of messages.
\end{hladefinition}

\begin{hladefinition}{def-logical-time-interval}{logical time interval}
The representation of the distance between two points on the time axis. Logical time interval is used to represent a time-regulating federate's lookahead and by the RTI to perform arithmetic on logical time values.
\end{hladefinition}

\begin{hladefinition}{def-lookahead}{lookahead}
A logical time interval provided by joined federates that become time-regulating. When added to the time-regulating joined federate's time position, the resulting timestamp is used to calculate the bound on the timestamps that the time-regulating joined federate can use to send timestamp order (TSO) messages.
\end{hladefinition}

\begin{hladefinition}{def-lost-joined-federate}{lost joined federate}
A previously joined federate that has been disconnected from the runtime infrastructure (RTI) as a result of a fault so that the joined federate can no longer continue in the federation execution in a High Level Architecture (HLA) compliant manner.
\end{hladefinition}

\begin{hladefinition}{def-management-object-model-mom}{Management Object Model (MOM)}
A group of predefined High Level Architecture (HLA) constructs (object and interaction classes) that provide the following:
\begin{hladefinitionlistroomy}[32.04pt]
\item Access to federation execution operating information
\item Insight into the operations of joined federates and the runtime infrastructure (RTI)
\item Control of the functioning of the RTI, the federation execution, and the individual joined federates
\end{hladefinitionlistroomy}
\end{hladefinition}

\begin{hladefinition}{def-management-object-model-mom-and-initialization-module-mim}{Management Object Model (MOM) and Initialization Module (MIM)}
A subset of the federation object model (FOM) that contains object model template (OMT) tables that describe the High Level Architecture (HLA) MOM. The MIM also contains additional predefined HLA constructs such as object and interaction roots, data types, transportation types, and dimensions. HLA specifies a standard MIM that is incorporated into all FOM Document Data (FDD) automatically by the runtime infrastructure (RTI). The standard MIM can be replaced with a user-supplied MIM containing the standard MIM plus extensions.
\end{hladefinition}

\begin{hladefinition}{def-message}{message}
A change of object instance attribute value(s), an interaction, a directed interaction, or a deletion of an existing object instance, often associated with a particular point on the time axis, as denoted by the associated timestamp.
\end{hladefinition}

\begin{hladefinition}{def-null-designator}{null designator}
A designator reserved to indicate an empty value that is distinguishable from all other designators. A null designator is guaranteed to compare unequal to any other designator with a nonempty value.
\end{hladefinition}

\begin{hladefinition}{def-object-class}{object class}
A fundamental element of a conceptual representation for a federate that reflects the real world at levels of abstraction and resolution appropriate for federate interoperability. An object class is a template for a set of characteristics that is common to a group of object instances. These characteristics correspond to the class attributes and class directed interactions that individual federates may publish and to which other federates may subscribe.
\end{hladefinition}

\begin{hladefinition}{def-object-instance}{object instance}
A unique instantiation of an object class that is independent of all other instances of that object class. At any point during a federation execution, the state of a High Level Architecture (HLA) object instance is defined as the collection of the values of all its instance attributes.
\end{hladefinition}

\begin{hladefinition}{def-object-model}{object model}
A system specification defined primarily by class characteristics and relationships. The High Level Architecture (HLA) idea of an object model is similar in many ways, but not identical, to the common idea of an object model in object-oriented literature.
\end{hladefinition}

\begin{hladefinition}{def-object-model-framework}{object model framework}
The rules and terminology used to describe High Level Architecture (HLA) object models.
\end{hladefinition}
