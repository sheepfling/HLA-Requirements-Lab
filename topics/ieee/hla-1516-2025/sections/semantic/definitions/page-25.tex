\begin{hladefinition}[0pt]{def-range-lower-bound}{range lower bound}
The first component of the ordered pair of values that is part of a range.
\HLADefinitionNote[11.58pt]{See 9.1 of IEEE Std 1516.1\HLAStandardMark-2025.}
\end{hladefinition}

\begin{hladefinition}{def-range-upper-bound}{range upper bound}
The second component of the ordered pair of values that is part of a range.
\HLADefinitionNote[11.58pt]{See 9.1 of IEEE Std 1516.1\HLAStandardMark-2025.}
\end{hladefinition}

\begin{hladefinition}{def-received-class}{received class}
The class that was an interaction's candidate received class at the joined federate when that interaction was received at that joined federate via an invocation of the \HLAService{Receive Interaction} \HLAPrintersDagger{} or \HLAService{Receive Directed Interaction} \HLAPrintersDagger{} service.
\HLADefinitionNote[11.58pt]{See 5.1.3 of IEEE Std 1516.1\HLAStandardMark-2025.}
\end{hladefinition}

\begin{hladefinition}{def-received-parameters}{received parameters}
The set of parameters received when the \HLAService{Receive Interaction} \HLAPrintersDagger{} or \HLAService{Receive Directed Interaction} \HLAPrintersDagger{} service is invoked. These parameters consist of the subset of the sent parameters of an interaction that are available parameters of the interaction's received class.
\HLADefinitionNote[11.58pt]{See 5.1.3 of IEEE Std 1516.1\HLAStandardMark-2025.}
\end{hladefinition}

\begin{hladefinition}{def-receive-order-ro}{receive order (RO)}
A characteristic of no ordering guarantee for messages. Messages that are received as RO messages will be received in an arbitrary order by the respective joined federate. A timestamp value will be provided with the message if one was specified when the message was sent, but that timestamp has no bearing on message receipt order.
\end{hladefinition}

\begin{hladefinition}{def-reflect}{reflect}
To receive new values for one or more instance attributes via invocation of the \HLAService{Reflect Attribute Values} \HLAPrintersDagger{} service.
\HLADefinitionNote[11.58pt]{See 6.11 of IEEE Std 1516.1\HLAStandardMark-2025.}
\end{hladefinition}

\begin{hladefinition}{def-reflected-instance-attribute}{reflected instance attribute}
An instance attribute that is represented but not explicitly modeled in a joined federate. The reflecting joined federate accepts new values of the reflected instance attribute as they are produced by some other federation member and provided to it by the runtime infrastructure (RTI), via the \HLAService{Reflect Attribute Values} \HLAPrintersDagger{} service.
\end{hladefinition}

\begin{hladefinition}{def-region}{region}
A generic term that refers to either a region specification or a region realization. If not using data distribution management (DDM), region arguments may be ignored.
\HLADefinitionNote[11.58pt]{See 9.1 of IEEE Std 1516.1\HLAStandardMark-2025.}
\end{hladefinition}

\begin{hladefinition}{def-region-realization}{region realization}
A region specification (set of ranges) that is associated with an instance attribute for update, with a sent interaction, or with a class attribute or interaction class for a subscription. Region realizations are created from region specifications via the \HLAService{Commit Region Modifications} (only when modifying a region specification from which region realizations are already derived), \HLAService{Register Object Instance With Regions}, \HLAService{Associate Regions for Updates}, \HLAService{Subscribe Object Class Attributes With Regions}, \HLAService{Subscribe Interaction Class With Regions}, \HLAService{Send Interaction With Regions}, or \HLAService{Request Attribute Value Update With Regions} services.
\HLADefinitionNote[11.58pt]{See 9.1.1 of IEEE Std 1516.1\HLAStandardMark-2025.}
\end{hladefinition}

\begin{hladefinition}{def-region-specification}{region specification}
A set of ranges. Region specifications are created using the \HLAService{Create Region} service, and a runtime infrastructure (RTI) is notified of changes to a region specification using the \HLAService{Commit Region Modifications} service.
\HLADefinitionNote[11.58pt]{See 9.1.1 of IEEE Std 1516.1\HLAStandardMark-2025.}
\end{hladefinition}
