\begin{hladefinition}[0pt]{def-time-axis}{time axis}
A totally ordered sequence of discrete values in which each value typically represents an HLA\linebreak
instant of time in the physical system being modeled. For any two points, T1 and T2, on the time axis, if T1\linebreak
< T2, T1 represents an instant of time that occurs before the instant represented by T2. The sequence begins\linebreak
with an initial value, for which no point is less, and ends with a final value, for which no point is greater.
\end{hladefinition}

\begin{hladefinition}{def-time-constrained-federate}{time-constrained federate}
A joined federate that may receive timestamp order (TSO) messages and whose time advances are constrained by other joined federates within a federation execution.
\HLADefinitionNote[9.54pt]{See 8.1 of IEEE Std 1516.1\HLAStandardMark-2025.}
\end{hladefinition}

\begin{hladefinition}{def-time-management}{time management}
A collection of High Level Architecture (HLA) services that support controlled message ordering and delivery to the cooperating joined federates within a federation execution in a way that is consistent with federation requirements.
\end{hladefinition}

\begin{hladefinition}{def-time-position}{time position}
A joined federate's association with a point on the time axis.
\end{hladefinition}

\begin{hladefinition}[12.18pt]{def-time-regulating-federate}{time-regulating federate}
A joined federate that may send timestamp order (TSO) messages and that constrains the time advances of other joined federates within a federation execution.
\HLADefinitionNote[11.58pt]{See 8.1 of IEEE Std 1516.1\HLAStandardMark-2025.}
\end{hladefinition}

\begin{hladefinition}[12.18pt]{def-timestamp-of-message-or-save}{timestamp (of message or save)}
The association of a logical time with an activity of a federate (e.g., updating instance attribute values, sending interactions, and federation save).
\end{hladefinition}

\begin{hladefinition}[12.18pt]{def-timestamp-order-tso}{timestamp order (TSO)}
An ordering of messages provided by a runtime infrastructure (RTI) for joined federates making use of time management services and messages containing timestamps. Messages having different timestamps are said to be delivered in TSO if for any two messages, M1 and M2 (timestamped with T1 and T2, respectively), that are delivered to a single joined federate where T1 < T2, then M1 is delivered before M2. Messages having the same timestamp will be delivered in an arbitrary order (i.e., no tie-breaking mechanism is provided by an RTI).
\end{hladefinition}

\begin{hladefinition}[12.18pt]{def-token}{token}
An attribute without a value, which conveys the information of which federate, if any, owns the attribute.
\end{hladefinition}

\begin{hladefinition}[12.18pt]{def-transportation-type}{transportation type}
A runtime infrastructure (RTI) provided means of transmitting messages between joined federates. Different categories of service are defined with different characteristics such as reliability of delivery and message latency.
\end{hladefinition}

\begin{hladefinition}{def-unspecified-dimensions}{unspecified dimensions}
The available dimensions of a class attribute, instance attribute, interaction class, or sent interaction less the specified dimensions of the region specification from which the region realization is derived.
\HLADefinitionNote[9.54pt]{See 9.1.3 of IEEE Std 1516.1\HLAStandardMark-2025.}
\end{hladefinition}

\begin{hladefinition}{def-update}{update}
To invoke the \HLAService{Update Attribute Values} service for one or more instance attributes.
\HLADefinitionNote[11.58pt]{See 6.10 of IEEE Std 1516.1\HLAStandardMark-2025.}
\end{hladefinition}

\begin{hladefinition}{def-update-rate}{update rate}
The rate at which instance attribute values are provided, either by an owning joined federate to the runtime infrastructure (RTI) or by the RTI to a subscribing joined federate.
\end{hladefinition}

\begin{hladefinition}[12.18pt]{def-update-region-set}{update region set}
A set of regions used for sending interactions or used for updating instance attributes. \HLASeeAlso{\HLATermReference{used for sending}\HLASemicolon{} \HLATermReference{used for update}.}
\end{hladefinition}
