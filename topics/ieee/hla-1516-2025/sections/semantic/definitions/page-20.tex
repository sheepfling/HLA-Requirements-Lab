\begin{hladefinition}[0pt]{def-federation}{federation}
A named set of federate applications and a common federation object model (FOM) that are used as a whole to achieve some specific objective.
\end{hladefinition}

\begin{hladefinition}{def-federation-execution}{federation execution}
The actual operation, over time, of a set of joined federates that are interconnected by a runtime infrastructure (RTI).
\end{hladefinition}

\begin{hladefinition}{def-federation-objectives}{federation objectives}
The statement of the problem that is to be addressed by the establishment and execution of a federation.
\end{hladefinition}

\begin{hladefinition}{def-federation-object-model-fom}{federation object model (FOM)}
A specification defining the information exchanged at runtime to achieve a given set of federation objectives. This information includes object classes, object class attributes, interaction classes, interaction parameters, and other relevant information. The FOM is specified to the runtime infrastructure (RTI) using one or more FOM modules. The RTI assembles a FOM using these FOM modules and one Management Object Model (MOM) and Initialization Module (MIM), which is provided automatically by the RTI or, optionally, provided to the RTI when the federation execution is created.
\end{hladefinition}

\begin{hladefinition}{def-federation-object-model-fom-document-data-fdd}{federation object model (FOM) Document Data (FDD)}
The data and information in a FOM that are used by the \HLAService{Create Federation Execution} service and successive \HLAService{Join Federation Execution} service invocations to configure the federation execution.
\end{hladefinition}

\begin{hladefinition}{def-federation-object-model-fom-module}{federation object model (FOM) module}
A partial FOM (containing some or all object model template (OMT) tables) that specifies a modular component of a FOM. A FOM module may contain classes not inherent to it but upon which the FOM module depends, i.e., superclasses to the modular components. These superclasses will be included in the FOM module as either complete or scaffolding definitions.
\end{hladefinition}

\begin{hladefinition}{def-federation-requirements}{federation requirements}
A statement that identifies a federation characteristic, constraint, process, or product that is unambiguous and testable and that is necessary for a federation to be acceptable for its intended use.
\end{hladefinition}

\begin{hladefinition}{def-federation-scenario}{federation scenario}
A set of initial conditions and timeline of significant events used within a federation execution to achieve federation objectives.
\end{hladefinition}

\begin{hladefinition}{def-final-time-value}{final time value}
The point on the time axis for which no other points occur after it.
\end{hladefinition}

\begin{hladefinition}{def-handle}{handle}
An identifier originated/created by the runtime infrastructure (RTI) that is unique to a federation execution.
\end{hladefinition}

\begin{hladefinition}{def-inherited-attribute}{inherited attribute}
A class attribute of an object class that was declared in a superclass of that object class in the object class hierarchy tree defined in the federation object model (FOM).
\end{hladefinition}

\begin{hladefinition}{def-inherited-dimension}{inherited dimension}
\begin{hladefinitionlist}[28.60pt]
\item Pertaining to an object class: a dimension of an object class that was declared in a superclass of that object class in the object class hierarchy tree defined in the federation object model (FOM) or simulation object model (SOM).
\item Pertaining to an interaction class: a dimension of an interaction class that was declared in a superclass of that interaction class in the interaction class hierarchy tree defined in the federation object model (FOM) or simulation object model (SOM).
\end{hladefinitionlist}
\end{hladefinition}

\begin{hladefinition}{def-inherited-directed-interaction-class}{inherited directed interaction class}
A directed interaction class of an object class that was declared in a superclass of that object class in the object class hierarchy tree defined in the federation object model (FOM).
\end{hladefinition}
