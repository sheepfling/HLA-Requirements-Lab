\begin{hladefinition}[0pt]{def-inherited-parameter}{inherited parameter}
An interaction parameter that was declared in a superclass of that interaction class in the interaction class hierarchy tree defined in the federation object model (FOM).
\end{hladefinition}

\begin{hladefinition}{def-initial-time-value}{initial time value}
The point on the time axis for which no other point occurs before it.
\end{hladefinition}

\begin{hladefinition}{def-in-scope}{in scope}
Of or pertaining to an instance attribute of an object instance for which all of the following apply:
\begin{hladefinitionlist}[28.60pt]
\item The object instance is known to the joined federate.
\item The instance attribute is owned by another joined federate.
\item The instance attribute's corresponding class attribute is one of the following:
  \begin{hladefinitionnumberlist}
  \item A subscribed attribute of the known class of the object instance, or
  \item A subscribed attribute of the known class of the object instance with regions, and the update region set of the instance attribute at the owning joined federate overlaps the subscription region set of the instance attribute's corresponding class attribute at the known class of the instance attribute at the subscribing joined federate.
  \end{hladefinitionnumberlist}
  \par\addvspace{9.96pt}%
  \hspace*{25.82pt}{\fontsize{9pt}{10.8pt}\selectfont NOTE---See 6.1 of IEEE Std 1516.1\HLAStandardMark-2025.}\par
\end{hladefinitionlist}
\end{hladefinition}

\begin{hladefinition}{def-instance-attribute}{instance attribute}
A named characteristic of an object instance denoted by a pair composed of the object instance designator and the attribute designator.
\end{hladefinition}

\begin{hladefinition}{def-interaction}{interaction}
An explicit action taken by a federate that may have some effect or impact on another federate within a federation execution.
\end{hladefinition}

\begin{hladefinition}{def-interaction-class}{interaction class}
A template for a set of characteristics that is common to a group of interactions. These characteristics correspond to the parameters that individual federates may associate with interactions.
\end{hladefinition}

\begin{hladefinition}{def-interaction-parameters}{interaction parameters}
The information associated with an interaction that a federate potentially affected by the interaction may receive to calculate the effects of that interaction on its current state.
\end{hladefinition}

\begin{hladefinition}{def-joined-federate}{joined federate}
A member of a federation execution, actualized by a federate application invoking the \HLAService{Join Federation Execution} service as prescribed in IEEE Std 1516.1\HLAStandardMark-2025. \HLASeeAlso{\HLATermReference{federate application}.}
\end{hladefinition}

\begin{hladefinition}{def-known-class}{known class}
\begin{hladefinitionlist}[28.60pt]
\item An object instance's registered class if the joined federate knows about the object instance as a result of having registered it, or
\item An object instance's discovered class if the joined federate knows about the object instance as a result of having discovered it.
\end{hladefinitionlist}
\end{hladefinition}

\begin{hladefinition}{def-known-object-instance}{known object instance}
An object instance that a given joined federate has either registered or discovered and that the joined federate has not subsequently deleted (globally or locally) or been notified to remove. \HLASeeAlso{\HLATermReference{register}\HLASemicolon{} \HLATermReference{discover}\HLASemicolon{} \HLATermReference{delete}\HLASemicolon{} \HLATermReference{local delete}\HLASemicolon{} \HLATermReference{remove}.}
\end{hladefinition}

\begin{hladefinition}{def-last-known-time-position}{last known time position}
The last time position to which a lost joined federate was successfully granted, as seen from the remaining federation execution.
\end{hladefinition}

\begin{hladefinition}{def-local-delete}{local delete}
To invoke the \HLAService{Local Delete Object Instance} service to inform the runtime infrastructure (RTI) that it is to treat the specified object instance as if the RTI had never notified the joined federate to discover the object instance (however, the object instance is not to be eliminated and may be rediscovered). \HLASeeAlso{\HLATermReference{delete}.}
\HLADefinitionNote{See 6.18 of IEEE Std 1516.1\HLAStandardMark-2025.}
\end{hladefinition}
