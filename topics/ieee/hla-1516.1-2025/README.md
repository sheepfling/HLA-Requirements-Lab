# IEEE HLA 1516.1-2025

Ingested from `HLA_1516_1_2025_LaTeX_FINAL_HANDOFF.zip`.

The editable LaTeX/Python source is kept directly in this document directory. The document-level `build.py` provides the repository-standard entry point.

This is an unofficial LaTeX recreation. The separately held licensed/reference PDF is not part of the source workflow.

Rendered PDFs, extracted raster assets, and comparison images from the handoff remain local-only and are ignored by the repository policy. The intended long-term source of truth is the text-based LaTeX/Python reconstruction.

## Build

Requirements are documented in [`BUILDING.md`](BUILDING.md).

```powershell
python build.py build
python build.py clean
```
