  \HLAFixedBlock{90.000}{493.806}{432.000}{\rmfamily\raggedright}{9.96}{12.00}{%
    The \emph{Delete Object Instance} service shall inform the federation that an object instance with the specified%
  }
  \HLAFixedBlock{89.999}{505.805}{432.001}{\rmfamily\raggedright}{9.96}{12.00}{%
    designator, which has the \textbf{HLAprivilegeToDeleteObject} instance attribute that is owned by the joined%
  }
  \HLAFixedBlock{89.999}{517.805}{432.001}{\rmfamily\raggedright}{9.96}{12.00}{%
    federate, is to be removed from the federation execution. Once the object instance is removed from the%
  }
  \HLAFixedBlock{89.999}{529.805}{432.001}{\rmfamily\raggedright}{9.96}{12.00}{%
    federation execution, the designator shall not be reused and all joined federates that owned attributes of the%
  }
  \HLAFixedBlock{89.999}{541.805}{432.001}{\rmfamily\raggedright}{9.96}{12.00}{%
    object instance shall no longer own those attributes. The object instance name may be reused for%
  }
  \HLAFixedBlock{89.999}{553.805}{432.001}{\rmfamily\raggedright}{9.96}{12.00}{%
    subsequently registered objects. The RTI shall use the \emph{Remove Object Instance \textdagger{}} service to inform all other%
  }
  \HLAFixedBlock{89.999}{565.804}{432.001}{\rmfamily\raggedright}{9.96}{12.00}{%
    joined federates which know the object instance that the object instance has been deleted. The invoking%
  }
  \HLAFixedBlock{89.999}{577.804}{432.001}{\rmfamily\raggedright}{9.96}{12.00}{%
    joined federate shall own the \textbf{HLAprivilegeToDeleteObject} attribute of the specified object instance.%
  }
  \HLAFixedBlock{89.999}{601.804}{432.001}{\rmfamily\raggedright}{9.96}{12.00}{%
    The preferred order type (see 8.1.3) of the sent message representing a \emph{Delete Object Instance} service%
  }
  \HLAFixedBlock{89.999}{613.804}{432.001}{\rmfamily\raggedright}{9.96}{12.00}{%
    invocation shall be based on the preferred order type of the \textbf{HLAprivilegeToDeleteObject} attribute of the%
  }
  \HLAFixedBlock{89.999}{625.803}{432.001}{\rmfamily\raggedright}{9.96}{12.00}{%
    specified object instance. If preferred order type of the \textbf{HLAprivilegeToDeleteObject} attribute of the%
  }
  \HLAFixedBlock{89.999}{637.803}{432.001}{\rmfamily\raggedright}{9.96}{12.00}{%
    specified object instance is TSO, the joined federate invoking this service is time-regulating, and the%
  }
  \HLAFixedBlock{89.999}{649.803}{432.001}{\rmfamily\raggedright}{9.96}{12.00}{%
    timestamp argument is present, this service shall return a federation-unique message retraction designator.%
  }
  \HLAFixedBlock{89.999}{661.803}{432.001}{\rmfamily\raggedright}{9.96}{12.00}{%
    Otherwise, no message retraction designator shall be returned. A timestamp value should be provided if the%
  }
  \HLAFixedBlock{89.999}{673.803}{432.001}{\rmfamily\raggedright}{9.96}{12.00}{%
    preferred order type of the \textbf{HLAprivilegeToDeleteObject} attribute of the specified object instance is TSO%
  }
  \HLAFixedBlock{89.999}{685.802}{432.001}{\rmfamily\raggedright}{9.96}{12.00}{%
    and the joined federate invoking this service is time-regulating.%
