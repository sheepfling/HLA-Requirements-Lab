    4.12 \emph{Resign Federation Execution} service%
  }
  \HLAFixedBlock{90.000}{364.806}{433.283}{\rmfamily}{9.96}{12.00}{%
    The \emph{Resign Federation Execution} service shall indicate the requested cessation of federation participation.\linebreak%
    Once a federate resigns from the federation execution, its federate designator shall not be reused in the same\linebreak%
    federation execution. Before resigning, ownership of instance attributes held by the joined federate should\linebreak%
    be resolved. The joined federate may transfer ownership of these instance attributes to other joined\linebreak%
    federates, unconditionally divest them for ownership acquisition at a later point, or delete the object instance\linebreak%
    of which they are a part (assuming the joined federate has the privilege to delete these object instances). As\linebreak%
    a convenience to the joined federate, the \emph{Resign Federation Execution} service shall accept an action\linebreak%
    argument that directs the RTI to perform zero or more of the following actions:
  }
  \HLAFixedBlock{100.020}{463.804}{11.160}{\rmfamily\raggedright}{9.96}{12.00}{%
    ---
  }
  \HLAFixedBlock{121.980}{463.804}{400.020}{\rmfamily}{9.96}{12.00}{%
    Unconditionally divest all owned instance attributes for future ownership acquisition. This action\linebreak%
    shall place the instance attributes into an unowned state (implying that their values are not being\linebreak%
    updated), which shall make them eligible for ownership by another joined federate. See Clause 7 for\linebreak%
    a more detailed description.
  }
  \HLAFixedBlock{100.020}{514.803}{11.160}{\rmfamily\raggedright}{9.96}{12.00}{%
    ---
  }
  \HLAFixedBlock{121.979}{514.803}{400.021}{\rmfamily}{9.96}{12.00}{%
    Delete all object instances for which the joined federate has that privilege (implied invocation of the\linebreak%
    \emph{Delete Object Instance} service).
  }
  \HLAFixedBlock{100.020}{541.803}{11.160}{\rmfamily\raggedright}{9.96}{12.00}{%
    ---
  }
  \HLAFixedBlock{121.979}{541.803}{400.021}{\rmfamily}{9.96}{12.00}{%
    Cancel all pending instance attribute ownership acquisitions. The use of this directive may interfere\linebreak%
    with the intended semantics of negotiated instance attribute ownership divestiture by allowing\linebreak%
    instance attributes divested in this way to be unowned (because the cancellation directive may not\linebreak%
    succeed).
  }
