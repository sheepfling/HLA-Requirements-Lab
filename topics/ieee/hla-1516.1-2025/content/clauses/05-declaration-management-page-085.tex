  \HLAFixedBlock{90.007}{501.779}{431.993}{\rmfamily\raggedright}{9.96}{12.00}{%
    Figure 10 depicts the state of an arbitrary object class, and it deals with object classes at two levels. First, it%
  }
  \HLAFixedBlock{90.007}{513.779}{431.993}{\rmfamily\raggedright}{9.96}{12.00}{%
    establishes that each class attribute of the object class has some state worth modeling. Second, it establishes%
  }
  \HLAFixedBlock{90.007}{525.779}{431.993}{\rmfamily\raggedright}{9.96}{12.00}{%

  }
  \HLAFixedBlock{90.007}{537.778}{431.993}{\rmfamily\raggedright}{9.96}{12.00}{%

  \HLAFixedBlock{90.007}{561.778}{431.993}{\rmfamily\raggedright}{9.96}{12.00}{%
    Conceptually, the state of an object class comprises the state of the class attributes of that object class and of%
  }
  \HLAFixedBlock{90.007}{573.778}{431.993}{\rmfamily\raggedright}{9.96}{12.00}{%
    the object instances of that object class. Furthermore, the state of an object instance comprises the state of%
  }
  \HLAFixedBlock{90.000}{585.786}{432.000}{\rmfamily\raggedright}{9.96}{12.00}{%
    the instance attributes of that object instance. There is a correspondence between the instance attributes and%
  }
  \HLAFixedBlock{90.000}{597.785}{432.000}{\rmfamily\raggedright}{9.96}{12.00}{%
    their corresponding class attributes. This correspondence is modeled via the index to each attribute. A%
  }
  \HLAFixedBlock{89.999}{609.785}{432.001}{\rmfamily\raggedright}{9.96}{12.00}{%
    reference to an instance attribute (\emph{i, k, j}) and to a class attribute (\emph{i, j}) with the same\emph{ i}s and same \emph{j}s means that%
  }
  \HLAFixedBlock{89.999}{621.785}{432.001}{\rmfamily\raggedright}{9.96}{12.00}{%

  }
  \HLAFixedBlock{89.999}{633.785}{432.001}{\rmfamily\raggedright}{9.96}{12.00}{%
    correspondence is because having the same \emph{j}s means that they refer to the same attribute designator, and%
  }
  \HLAFixedBlock{89.999}{645.785}{432.001}{\rmfamily\raggedright}{9.96}{12.00}{%

  }
