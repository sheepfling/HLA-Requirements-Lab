  \HLAFixedBlock{90}{69.79}{432}{\rmfamily}{9.96}{12}{%
    Federates use the state of the object instances as one of the primary means of communication. At any point\linebreak
    during a federation execution, at most one federate or the RTI shall have the privilege to update the value of\linebreak
    a given object instance attribute. A joined federate that has the privilege to update values for an instance\linebreak
    attribute is said to own that instance attribute. There are specific (MOM) instance attributes that are owned\linebreak
    by the RTI. In some cases, an instance attribute may be unowned, neither owned by a federate nor the RTI.\linebreak
    The Ownership Management services allow joined federates to gain ownership of unowned instance\linebreak
    attributes, exchange ownership of instance attributes, or release ownership of instance attributes (possibly to\linebreak
    become unowned). The federate provides instance attribute values to the other federates in the federation\linebreak
    execution via Object Management services. The federate providing the instance attribute values is said to be\linebreak
    updating that instance attribute. Federates receiving those values are said to be reflecting that instance\linebreak
    attribute.%
  }

  \HLAFixedBlock{90}{213.78}{432}{\rmfamily}{9.96}{12}{%
    Each object instance shall have a designator. The value of an object instance designator shall be unique for\linebreak
    each federation execution. Object instance designators shall be dynamically generated by the RTI.%
  }

  \HLAFixedBlock{90}{249.78}{432}{\rmfamily}{9.96}{12}{%
    The FOM framework also allows for interaction classes for each object model. The types of interactions\linebreak
    possible and their parameters are specified within the FOM.%
  }

  \HLAFixedBlock{90}{285.78}{432}{\rmfamily}{9.96}{12}{%
    A \textbf{federation} is the combination of a particular FOM, a particular set of federates, and the HLA services. A\linebreak
    federation is designed for a specific purpose using a commonly understood FOM and a set of federates that\linebreak
    may associate their individual semantics with that object model. A federation execution is an instance of the\linebreak
    \emph{Create Federation Execution} service invocation and entails executing the federation with a specific FOM\linebreak
    and RTI and using various execution details.%
  }

    There are various entities (e.g., object classes, attributes, interaction classes, parameters, dimensions,\linebreak
    regions, federates, object instances) referenced in this document that may have the following different\linebreak
    views:%
  }

  \HLAFixedDashList{90}{430.80}{432}{6}{%
    \item Name: textual or for communication between federates.
    \item Handle: capable of being manipulated by a computer or for communication between a federate and\linebreak
      the RTI. A handle is originated by the RTI, federation execution-wide unique, and unpredictable.\linebreak
      The handle for a class attribute that is inherited shall be the same as the handle that is assigned to the\linebreak
      class attribute in the object class in which it is declared. The handle for a parameter that is inherited\linebreak
      shall be the same as the handle that is assigned to the parameter in the interaction class in which it is\linebreak
      declared.
  }
