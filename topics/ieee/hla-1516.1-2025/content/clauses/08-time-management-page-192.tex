  \HLAFixedBlock{90.000}{274.805}{432.000}{\rmfamily\raggedright}{9.96}{12.00}{%

  }
  \HLAFixedBlock{90.000}{286.805}{432.000}{\rmfamily\raggedright}{9.96}{12.00}{%
    of the joined federate. If the joined federate is time-regulating, the argument shall equal the joined federate’s%
  }
  \HLAFixedBlock{90.000}{298.805}{432.000}{\rmfamily\raggedright}{9.96}{12.00}{%
    current logical time. The RTI shall provide the joined federate with the smallest possible logical time that is%
  }
  \HLAFixedBlock{90.000}{310.805}{432.000}{\rmfamily\raggedright}{9.96}{12.00}{%
    greater than or equal to the logical time of the joined federate and for which all other constraints necessary to%
  }
  \HLAFixedBlock{90.000}{322.805}{432.000}{\rmfamily\raggedright}{9.96}{12.00}{%
    ensure TSO message delivery are satisfied. In other words, in general, the provided federation time shall be%
  }
  \HLAFixedBlock{90.000}{334.805}{432.000}{\rmfamily\raggedright}{9.96}{12.00}{%
    less than or equal to the joined federate’s GALT. If the joined federate’s current logical time is greater than%
  }
  \HLAFixedBlock{90.000}{346.804}{432.000}{\rmfamily\raggedright}{9.96}{12.00}{%
    its GALT, then the joined federate shall not become time-constrained until the joined federate’s GALT%
  }
  \HLAFixedBlock{90.000}{358.804}{432.000}{\rmfamily\raggedright}{9.96}{12.00}{%
    advances beyond its logical time. See 8.1.2 for more explanation on this point.%
  }
  \HLAFixedBlock{90.000}{382.804}{432.000}{\rmfamily\raggedright}{9.96}{12.00}{%
    When a joined federate changes to be time-constrained, TSO messages stored in the RTI’s internal queues%

  \HLAFixedBlock{90.000}{394.804}{432.000}{\rmfamily\raggedright}{9.96}{12.00}{%

  \HLAFixedBlock{90.000}{406.803}{432.000}{\rmfamily\raggedright}{9.96}{12.00}{%
    TSO messages delivered to the joined federate before it becomes time-constrained, possibly including%
  }
  \HLAFixedBlock{90.000}{418.803}{432.000}{\rmfamily\raggedright}{9.96}{12.00}{%
    messages with timestamps greater than or equal to the joined federate’s current logical time, shall be%

    delivered as RO messages.%
