  \HLAFixedBlock{90.000}{69.120}{432.000}{\sffamily\raggedright}{12.00}{12.00}{%
    \textbf{9. Data distribution management (DDM)}%
  }
  \HLAServiceHeadingAt{97.403}{%
    \textbf{9.1 Overview}%
  }
  \HLAFixedBlock{90.000}{120.786}{432.000}{\rmfamily\raggedright}{9.96}{12.00}{%
    DDM services may be used by joined federates to reduce both the transmission and the reception of%
  }
  \HLAFixedBlock{90.000}{131.766}{432.000}{\rmfamily\raggedright}{9.96}{12.00}{%
    irrelevant data. Whereas DM services provide information on data relevance at the class attribute level,%
  }
  \HLAFixedBlock{90.001}{142.805}{431.999}{\rmfamily\raggedright}{9.96}{12.00}{%
    DDM services add the capability to further refine the data requirements at the instance attribute level.%
  }
  \HLAFixedBlock{90.001}{153.785}{431.999}{\rmfamily\raggedright}{9.96}{12.00}{%
    Similarly, whereas DM services provide information on data relevance at the interaction class level, DDM%
  }
  \HLAFixedBlock{90.001}{164.765}{431.999}{\rmfamily\raggedright}{9.96}{12.00}{%
    services add the capability to further refine the data requirements at the specific interaction level. Producers%
  }
  \HLAFixedBlock{90.001}{175.805}{431.999}{\rmfamily\raggedright}{9.96}{12.00}{%
    and consumers of data communicated between joined federates may use the DDM services to bound the%
  }
  \HLAFixedBlock{90.001}{186.785}{431.999}{\rmfamily\raggedright}{9.96}{12.00}{%
    relevance of such communicated data. As a result, the RTI can help recognize the irrelevant data and reduce%
  }
  \HLAFixedBlock{90.001}{197.765}{431.999}{\rmfamily\raggedright}{9.96}{12.00}{%
    its delivery to consumers. The relevance of communicating interactions or instance attribute updates is%
  }
  \HLAFixedBlock{90.001}{208.804}{431.999}{\rmfamily\raggedright}{9.96}{12.00}{%
    expressed by giving a bounding for relevant communication in a space of user-defined dimensions. Both%
  }
  \HLAFixedBlock{90.002}{219.784}{431.998}{\rmfamily\raggedright}{9.96}{12.00}{%
    consumers and producers specify the upper and lower bounds for the relevant portion of that space, and the%
  }
  \HLAFixedBlock{90.002}{230.764}{431.998}{\rmfamily\raggedright}{9.96}{12.00}{%
    overlap of producers’ and consumers’ region sets is used to bound relevant communication.%
  }
  \HLAServiceComponentHeadingAt{253.665}{%
    \textbf{9.1.1 Definitions for DDM}%
  }
  \HLAFixedBlock{90.002}{277.804}{431.998}{\rmfamily\raggedright}{9.96}{12.00}{%
    The DDM services shall be based on the following concepts and terms:%
  }
  \HLAFixedBlock{100.022}{292.804}{421.978}{\rmfamily\raggedright}{9.96}{12.00}{%
    a)%
  }
  \HLAFixedBlock{121.983}{292.804}{400.017}{\rmfamily\raggedright}{9.96}{12.00}{%
    A \textbf{dimension} shall be a named interval of nonnegative integers. The interval shall be defined by an%
  }
  \HLAFixedBlock{121.982}{303.784}{400.018}{\rmfamily\raggedright}{9.96}{12.00}{%
    ordered pair of values. The first value is 0 (zero) for every dimension. The second value, which can%
  }
  \HLAFixedBlock{121.982}{314.764}{400.018}{\rmfamily\raggedright}{9.96}{12.00}{%
    vary for each dimension, is that dimension’s upper bound as specified in the FDD.%
  }
  \HLAFixedBlock{100.021}{325.803}{421.979}{\rmfamily\raggedright}{9.96}{12.00}{%
    b)%
  }
  \HLAFixedBlock{121.981}{325.803}{400.019}{\rmfamily\raggedright}{9.96}{12.00}{%
    A \textbf{range} shall be a continuous semi-open interval on a dimension. The interval is defined by an%
  }
  \HLAFixedBlock{121.981}{337.803}{400.019}{\rmfamily\raggedright}{9.96}{12.00}{%
    ordered pair of values. The first component of the pair shall be called \textbf{range lower bound}, and the%
  }
  \HLAFixedBlock{121.982}{349.803}{400.018}{\rmfamily\raggedright}{9.96}{12.00}{%
    second component shall be called \textbf{range upper bound}. The range upper bound shall be strictly%
  }
  \HLAFixedBlock{121.983}{361.803}{400.017}{\rmfamily\raggedright}{9.96}{12.00}{%
    greater than the range lower bound. The minimum possible difference between a range lower bound%
  }
  \HLAFixedBlock{121.983}{373.803}{400.017}{\rmfamily\raggedright}{9.96}{12.00}{%
    and a range upper bound shall be 1 (one).%
  }
  \HLAFixedBlock{100.023}{385.802}{421.977}{\rmfamily\raggedright}{9.96}{12.00}{%
    c)%
  }
  \HLAFixedBlock{121.984}{385.802}{400.016}{\rmfamily\raggedright}{9.96}{12.00}{%
    A \textbf{region specification} shall be a set of ranges. The dimensions contained in a region specification%
  }
  \HLAFixedBlock{121.983}{397.802}{400.017}{\rmfamily\raggedright}{9.96}{12.00}{%
    shall be the dimensions of the ranges that are included in the region specification. A region%
  }
  \HLAFixedBlock{121.983}{409.802}{400.017}{\rmfamily\raggedright}{9.96}{12.00}{%
    specification shall contain at most one range for any given dimension. Each range in a region%
  }
  \HLAFixedBlock{121.983}{421.802}{400.017}{\rmfamily\raggedright}{9.96}{12.00}{%
    specification shall be defined in terms of the bounds [0, the corresponding dimension’s upper%
  }
  \HLAFixedBlock{121.983}{433.802}{400.017}{\rmfamily\raggedright}{9.96}{12.00}{%
    bound). %
  }
  \HLAFixedBlock{100.023}{445.802}{421.977}{\rmfamily\raggedright}{9.96}{12.00}{%
    d)%
  }
  \HLAFixedBlock{121.983}{445.802}{400.017}{\rmfamily\raggedright}{9.96}{12.00}{%
    A \textbf{region template} shall be an incomplete region specification where one or more dimensions have%
  }
  \HLAFixedBlock{121.983}{457.801}{400.017}{\rmfamily\raggedright}{9.96}{12.00}{%
    not been assigned ranges.%
  }
  \HLAFixedBlock{100.023}{469.801}{421.977}{\rmfamily\raggedright}{9.96}{12.00}{%
    e)%
  }
  \HLAFixedBlock{121.984}{469.801}{400.016}{\rmfamily\raggedright}{9.96}{12.00}{%
    A \textbf{region realization} shall be a region specification that is associated with an instance attribute for%
  }
  \HLAFixedBlock{121.983}{481.801}{400.017}{\rmfamily\raggedright}{9.96}{12.00}{%
    update, with a sent interaction or with a class attribute or interaction class for subscription. The%
  }
  \HLAFixedBlock{121.983}{493.801}{400.017}{\rmfamily\raggedright}{9.96}{12.00}{%
    generic term \textbf{region} may be used in circumstances where a region specification, a region realization,%
  }
  \HLAFixedBlock{121.984}{505.801}{400.016}{\rmfamily\raggedright}{9.96}{12.00}{%
    or both apply.%
  }
  \HLAFixedBlock{100.024}{517.800}{421.976}{\rmfamily\raggedright}{9.96}{12.00}{%
    f)%
  }
  \HLAFixedBlock{121.961}{517.800}{400.039}{\rmfamily\raggedright}{9.96}{12.00}{%
    The RTI shall provide the \textbf{default region}, which is defined as having the range [0, the range’s%
  }
  \HLAFixedBlock{121.984}{529.800}{400.016}{\rmfamily\raggedright}{9.96}{12.00}{%
    dimension’s upper bound) for each dimension found in the FDD. The default region shall have all%
  }
  \HLAFixedBlock{121.984}{541.800}{400.016}{\rmfamily\raggedright}{9.96}{12.00}{%
    dimensions found in the FDD, regardless of the class attribute or interaction class with which it is%
  }
  \HLAFixedBlock{121.983}{553.800}{400.017}{\rmfamily\raggedright}{9.96}{12.00}{%
    associated. The default region realization shall not have a region specification. There shall be no%
  }
  \HLAFixedBlock{121.983}{565.800}{400.017}{\rmfamily\raggedright}{9.96}{12.00}{%
    way for a joined federate to refer to the default region. If a joined federate creates a region that has as%
  }
  \HLAFixedBlock{121.983}{577.799}{400.017}{\rmfamily\raggedright}{9.96}{12.00}{%
    its dimensions all dimensions found in the FDD and has the range [0, the range’s dimension’s upper%
  }
  \HLAFixedBlock{121.983}{589.799}{400.017}{\rmfamily\raggedright}{9.96}{12.00}{%
    bound) for each dimension, this region shall be equivalent to the default region, but it is not the%
  }
  \HLAFixedBlock{121.983}{601.799}{400.017}{\rmfamily\raggedright}{9.96}{12.00}{%
    default region.%
  }
  \HLAFixedBlock{100.024}{613.799}{421.976}{\rmfamily\raggedright}{9.96}{12.00}{%
    g)%
  }
  \HLAFixedBlock{121.983}{613.799}{400.017}{\rmfamily\raggedright}{9.96}{12.00}{%
    A collection of attribute designator set and region designator set pairs shall be interpreted as a set of%
  }
  \HLAFixedBlock{121.983}{625.799}{400.017}{\rmfamily\raggedright}{9.96}{12.00}{%
    (attribute designator, region designator) pairs. The interpreted form can be viewed as if constructed%
  }
  \HLAFixedBlock{121.983}{637.798}{400.017}{\rmfamily\raggedright}{9.96}{12.00}{%
    in the following manner:%
  }
  \HLAFixedBlock{121.983}{652.798}{400.017}{\rmfamily\raggedright}{9.96}{12.00}{%
    1)%
  }
  \HLAFixedBlock{142.031}{652.798}{379.969}{\rmfamily\raggedright}{9.96}{12.00}{%
    The interpreted form begins as an empty set of (attribute designator, region designator) pairs.%
  }
  \HLAFixedBlock{121.983}{667.798}{400.017}{\rmfamily\raggedright}{9.96}{12.00}{%
    2)%
  }
  \HLAFixedBlock{142.040}{667.798}{379.960}{\rmfamily\raggedright}{9.96}{12.00}{%
    For each pair (of sets) in the attribute designator set and region designator set pair collection,%
  }
  \HLAFixedBlock{142.024}{679.798}{379.976}{\rmfamily\raggedright}{9.96}{12.00}{%
    create the cross product of the attribute designator set with its region designator set. The result%
  }
  \HLAFixedBlock{142.024}{691.798}{379.976}{\rmfamily\raggedright}{9.96}{12.00}{%
    is a collection of (attribute designator, region designator) pairs. The union of all such (attribute%
  }
  \HLAFixedBlock{142.024}{703.797}{379.976}{\rmfamily\raggedright}{9.96}{12.00}{%
    designator, region designator) pairs shall be the interpreted form.%
  }
