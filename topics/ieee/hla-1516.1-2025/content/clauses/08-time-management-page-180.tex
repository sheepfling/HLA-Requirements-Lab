  \HLAServiceComponentHeadingAt{327.642}{%
    \textbf{8.1.4 Message order type}%
  }
  \HLAFixedBlock{90.001}{351.781}{431.999}{\rmfamily\raggedright}{9.96}{12.00}{%
    Each message, sent or received, shall be either a timestamp order (TSO) message or an receive order (RO)%
  }
  \HLAFixedBlock{90.001}{363.781}{431.999}{\rmfamily\raggedright}{9.96}{12.00}{%
    message (see 8.1.11). The order type of a message shall be determined by several factors:%
  }
  \HLAFixedBlock{100.020}{375.781}{421.980}{\rmfamily\raggedright}{9.96}{12.00}{%
    a)%
  }
  \HLAFixedBlock{121.970}{375.781}{400.030}{\rmfamily\raggedright}{9.96}{12.00}{%
    Preferred order type: The preferred order type of a message shall be the same as the preferred order%
  }
  \HLAFixedBlock{121.981}{387.781}{400.019}{\rmfamily\raggedright}{9.96}{12.00}{%
    type of the data contained in the message (instance attribute values or interactions). Each class%
  }
  \HLAFixedBlock{121.981}{399.780}{400.019}{\rmfamily\raggedright}{9.96}{12.00}{%
    attribute and interaction class shall be provided with a preferred order type in the FDD that indicates%
  }
  \HLAFixedBlock{121.981}{411.780}{400.019}{\rmfamily\raggedright}{9.96}{12.00}{%
    the order type (TSO or RO) that shall be used when sending messages carrying values for instances%
  }
  \HLAFixedBlock{121.981}{423.780}{400.019}{\rmfamily\raggedright}{9.96}{12.00}{%
    of these classes. In the case of sent messages representing a \emph{Delete Object Instance} service%
  }
  \HLAFixedBlock{121.981}{435.780}{400.019}{\rmfamily\raggedright}{9.96}{12.00}{%
    invocation, the preferred order type of the message shall be based on the preferred order type of the%
  }
  \HLAFixedBlock{121.981}{447.780}{400.019}{\rmfamily\raggedright}{9.96}{12.00}{%
    \textbf{HLAprivilegeToDeleteObject}\emph{ }attribute of the specified object instance. Joined federates may use%
  }
  \HLAFixedBlock{121.980}{459.780}{400.020}{\rmfamily\raggedright}{9.96}{12.00}{%
    the \emph{Change Attribute Order Type} service to change the preferred order type of instance attributes;%
  }
  \HLAFixedBlock{121.980}{471.779}{400.020}{\rmfamily\raggedright}{9.96}{12.00}{%
    the preferred order type of class attributes may not be changed during a federation execution. Joined%
  }
  \HLAFixedBlock{121.980}{483.779}{400.020}{\rmfamily\raggedright}{9.96}{12.00}{%
    federates may use the \emph{Change Interaction Order Type} service to change the preferred order type of%
  }
  \HLAFixedBlock{121.981}{495.779}{400.019}{\rmfamily\raggedright}{9.96}{12.00}{%
    interaction classes. %
  }
  \HLAFixedBlock{100.021}{507.779}{421.979}{\rmfamily\raggedright}{9.96}{12.00}{%
    b)%
  }
  \HLAFixedBlock{121.939}{507.779}{400.061}{\rmfamily\raggedright}{9.96}{12.00}{%
    Presence of a timestamp: Each of the services that corresponds to sending a message shall include a%
  }
  \HLAFixedBlock{121.981}{519.779}{400.019}{\rmfamily\raggedright}{9.96}{12.00}{%
    timestamp argument if the preferred order type of any instance attribute or interaction class specified%
  }
  \HLAFixedBlock{121.980}{531.786}{400.020}{\rmfamily\raggedright}{9.96}{12.00}{%
    in the message is TSO and the joined federate is time-regulating. This timestamp argument is always%
  }
  \HLAFixedBlock{121.980}{543.785}{400.020}{\rmfamily\raggedright}{9.96}{12.00}{%
    optional, but it is recommended in such cases as the occurrence of a preferred order type of TSO and%
  }
  \HLAFixedBlock{121.980}{555.785}{400.020}{\rmfamily\raggedright}{9.96}{12.00}{%
    a time-regulating joined federate indicate an intent for TSO messages to be sent.%
  }
  \HLAFixedBlock{100.020}{567.785}{421.980}{\rmfamily\raggedright}{9.96}{12.00}{%
    c)%
  }
  \HLAFixedBlock{121.973}{567.785}{400.027}{\rmfamily\raggedright}{9.96}{12.00}{%
    Joined federate’s time status: Whether a joined federate is time-regulating shall determine whether a%
  }
  \HLAFixedBlock{121.980}{579.785}{400.020}{\rmfamily\raggedright}{9.96}{12.00}{%

  \HLAFixedBlock{121.980}{591.785}{400.020}{\rmfamily\raggedright}{9.96}{12.00}{%
    shall determine whether the joined federate can receive TSO messages.%
