  \HLAFixedBlock{90.000}{69.120}{514.000}{\rmfamily\raggedright}{12.00}{13.44}{%
    \textbf{11. Management object model (MOM)}%
  }
  \HLAFixedBlock{90.000}{101.363}{514.000}{\rmfamily\raggedright}{10.98}{12.30}{%
    \textbf{11.1 Overview}%
  }
  \HLAFixedBlock{90.000}{126.786}{514.000}{\rmfamily\raggedright}{9.96}{11.16}{%
    The MOM provides facilities for access to RTI operating information during federation execution. These%
  }
  \HLAFixedBlock{90.000}{138.785}{514.000}{\rmfamily\raggedright}{9.96}{11.16}{%
    MOM facilities can be used by joined federates to gain insight into the operations of the federation execution%
  }
  \HLAFixedBlock{90.000}{150.785}{514.000}{\rmfamily\raggedright}{9.96}{11.16}{%
    and to control the functioning of the RTI, the federation execution, and individual joined federates. The%
  }
  \HLAFixedBlock{90.000}{162.785}{514.000}{\rmfamily\raggedright}{9.96}{11.16}{%
    ability to monitor and control elements of a federation is required for proper functioning of a federation%
  }
  \HLAFixedBlock{90.000}{174.785}{514.000}{\rmfamily\raggedright}{9.96}{11.16}{%
    execution.%
  }
  \HLAFixedBlock{90.000}{198.785}{514.000}{\rmfamily\raggedright}{9.96}{11.16}{%
    Access and interchange of RTI information elements included in the MOM shall be accomplished by%
  }
  \HLAFixedBlock{89.999}{210.784}{514.001}{\rmfamily\raggedright}{9.96}{11.16}{%
    utilizing predefined HLA constructs, objects, and interactions in the same way that participating federates%
  }
  \HLAFixedBlock{89.999}{222.784}{514.001}{\rmfamily\raggedright}{9.96}{11.16}{%
    exchange information with other federates. The MOM shall use the object model template (OMT) format%
  }
  \HLAFixedBlock{89.999}{234.784}{514.001}{\rmfamily\raggedright}{9.96}{11.16}{%
    (found in IEEE Std 1516.2-2025) and syntax for the definition of these information and control elements.%
  }
  \HLAFixedBlock{89.999}{246.784}{514.001}{\rmfamily\raggedright}{9.96}{11.16}{%
    The RTI publishes object classes, registers object instances, and updates values of attributes of those object%
  }
  \HLAFixedBlock{89.999}{258.784}{514.001}{\rmfamily\raggedright}{9.96}{11.16}{%
    instances; subscribes to and receives some interactions; and publishes and sends other interactions. A joined%
  }
  \HLAFixedBlock{89.998}{270.783}{514.002}{\rmfamily\raggedright}{9.96}{11.16}{%
    federate charged with controlling a federation execution can subscribe to some or all of the object classes,%
  }
  \HLAFixedBlock{89.998}{282.783}{514.002}{\rmfamily\raggedright}{9.96}{11.16}{%
    reflect the updates, publish and send some interactions, and subscribe to and receive other interactions.%
  }
  \HLAFixedBlock{89.998}{294.783}{514.002}{\rmfamily\raggedright}{9.96}{11.16}{%
    Thus, while a FDD for a federation execution shall include all elements of the MOM, a federation may%
  }
  \HLAFixedBlock{89.998}{306.783}{514.002}{\rmfamily\raggedright}{9.96}{11.16}{%
    choose to use all, part, or none of the MOM standard classes and associated information elements. The%
  }
  \HLAFixedBlock{89.998}{318.783}{514.002}{\rmfamily\raggedright}{9.96}{11.16}{%
    MOM shall satisfy these requirements by utilizing predefined HLA constructs: object instances and%
  }
  \HLAFixedBlock{89.998}{330.783}{514.002}{\rmfamily\raggedright}{9.96}{11.16}{%
    interactions. The RTI shall publish object classes and shall register object instances and update values of%
  }
  \HLAFixedBlock{89.998}{342.782}{514.002}{\rmfamily\raggedright}{9.96}{11.16}{%
    attributes of those object instances; shall subscribe to and receive some interaction classes; and shall publish%
  }
  \HLAFixedBlock{89.998}{354.782}{514.002}{\rmfamily\raggedright}{9.96}{11.16}{%
    and send other interaction classes. A joined federate charged with controlling a federation execution can%
  }
  \HLAFixedBlock{89.998}{366.782}{514.002}{\rmfamily\raggedright}{9.96}{11.16}{%
    subscribe to the object classes, reflect the updates, publish and send some interaction classes, and subscribe%
  }
  \HLAFixedBlock{89.998}{378.782}{514.002}{\rmfamily\raggedright}{9.96}{11.16}{%
    to and receive other interaction classes.%
  }
  \HLAFixedBlock{89.998}{402.781}{514.002}{\rmfamily\raggedright}{9.96}{11.16}{%
    All MOM object classes, interaction classes, attributes, and parameters shall be predefined in the FDD.%
  }
  \HLAFixedBlock{89.998}{414.781}{514.002}{\rmfamily\raggedright}{9.96}{11.16}{%
    These definitions shall not be revised. However, MOM definitions may be extended. They may be%
  }
  \HLAFixedBlock{89.998}{426.781}{514.002}{\rmfamily\raggedright}{9.96}{11.16}{%
    augmented with additional subclasses, class attributes, or parameters. These new elements shall not be acted%
  }
  \HLAFixedBlock{89.998}{438.781}{514.002}{\rmfamily\raggedright}{9.96}{11.16}{%
    upon directly by the RTI; they may be acted on by federates in the federation.%
  }

    federation.%
