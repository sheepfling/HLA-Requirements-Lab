    \textbf{7.1.3 Privilege to delete object}%
  }
  \HLAFixedBlock{90.003}{429.780}{431.997}{\rmfamily\raggedright}{9.96}{12.00}{%
    All object classes shall have an available attribute called \textbf{HLAprivilegeToDeleteObject}. As with all other%
  }
  \HLAFixedBlock{90.002}{441.780}{431.998}{\rmfamily\raggedright}{9.96}{12.00}{%

  }
  \HLAFixedBlock{90.002}{453.780}{431.998}{\rmfamily\raggedright}{9.96}{12.00}{%
    at the known class of an object instance in order to be eligible for ownership of a corresponding%
  }
  \HLAFixedBlock{90.002}{465.780}{431.998}{\rmfamily\raggedright}{9.96}{12.00}{%
    \textbf{HLAprivilegeToDeleteObject} instance attribute.%
  }
  \HLAFixedBlock{90.002}{489.779}{431.998}{\rmfamily\raggedright}{9.96}{12.00}{%
    A \textbf{HLAprivilegeToDeleteObject} instance attribute shall be transferable among joined federates. All%
  }
  \HLAFixedBlock{90.002}{501.779}{431.998}{\rmfamily\raggedright}{9.96}{12.00}{%
    ownership management services for \textbf{HLAprivilegeToDeleteObject} instance attributes shall act the same as%
  }
  \HLAFixedBlock{90.002}{513.779}{431.998}{\rmfamily\raggedright}{9.96}{12.00}{%
    they are for all other instance attributes. The reason that a joined federate may want to own the%
  }
  \HLAFixedBlock{90.002}{525.779}{431.998}{\rmfamily\raggedright}{9.96}{12.00}{%
    \textbf{HLAprivilegeToDeleteObject} instance attribute, however, is different. Ownership of a typical instance%
  }
  \HLAFixedBlock{90.002}{537.778}{431.998}{\rmfamily\raggedright}{9.96}{12.00}{%
    attribute shall give a joined federate the privilege to provide new values for that instance attribute.%
  }
