    4.10 Report Federation Execution Members\emph{ \textdagger{}} service%
  }
  \HLAFixedBlock{90.000}{479.826}{433.211}{\rmfamily}{9.96}{12.00}{%
    The \emph{Report Federation Execution Members \textdagger{}} service provides the name of a currently executing federation\linebreak%
    and a list of its member federates. This service shall be invoked by the RTI at a federate in response to a \emph{List}\linebreak%
    \emph{Federation Execution Members} service invocation by the same federate. The provided federation execution\linebreak%
    exists indicator indicates if the named federation execution currently exists. 
  }
