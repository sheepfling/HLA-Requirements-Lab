  \HLAServiceComponentHeadingAt{69.646}{%
    5.1.7 Subscribing with update rate reduction%
  }
  \HLAFixedBlock{90.000}{93.785}{432.000}{\rmfamily\raggedright}{9.96}{12.00}{%
    A federate may, optionally, specify an update rate designator when subscribing to object class attributes.%
  }
  \HLAFixedBlock{90.000}{105.785}{432.000}{\rmfamily\raggedright}{9.96}{12.00}{%
    The update rate designator and a corresponding update rate shall be defined in the FDD of the federation%
  }
  \HLAFixedBlock{90.000}{117.785}{432.000}{\rmfamily\raggedright}{9.96}{12.00}{%
    execution. If an update rate designator is specified, the attributes shall be considered to be subscribed with%
  }
  \HLAFixedBlock{90.000}{129.785}{432.000}{\rmfamily\raggedright}{9.96}{12.00}{%
    the corresponding update rate. In case no update rate is specified, the attributes shall be considered to be%
  }
  \HLAFixedBlock{90.000}{141.785}{432.000}{\rmfamily\raggedright}{9.96}{12.00}{%
    subscribed with the default update rate; in other words, no update rate reduction shall take place. %
  }
  \HLAServiceHeadingAt{171.383}{%
    5.2 \emph{Publish Object Class Attributes} service%
  }
  \HLAFixedBlock{90.000}{196.806}{432.000}{\rmfamily\raggedright}{9.96}{12.00}{%
    The information provided by the joined federate via the \emph{Publish Object Class Attributes} service shall be used%
  }
  \HLAFixedBlock{89.999}{208.805}{432.001}{\rmfamily\raggedright}{9.96}{12.00}{%
    in multiple ways. First, it shall indicate an object class of which the joined federate may subsequently%
  }
  \HLAFixedBlock{89.999}{220.805}{432.001}{\rmfamily\raggedright}{9.96}{12.00}{%
    register object instances. Second, it shall indicate the class attributes of the object class for which the joined%
  }
  \HLAFixedBlock{89.999}{232.805}{432.001}{\rmfamily\raggedright}{9.96}{12.00}{%
    federate is capable of owning the corresponding instance attributes. Only the joined federate that owns an%
  }
  \HLAFixedBlock{89.999}{244.805}{432.001}{\rmfamily\raggedright}{9.96}{12.00}{%
    instance attribute shall provide values for that instance attribute to the federation. The joined federate may%
  }
  \HLAFixedBlock{89.999}{256.805}{432.001}{\rmfamily\raggedright}{9.96}{12.00}{%
    become the owner of an instance attribute and thereby be capable of updating its value in the following two%
  }
  \HLAFixedBlock{89.999}{268.805}{432.001}{\rmfamily\raggedright}{9.96}{12.00}{%
    ways:%
  }
  \HLAFixedBlock{100.019}{283.804}{421.981}{\rmfamily\raggedright}{9.96}{12.00}{%
    ---%
  }
  \HLAFixedBlock{121.979}{283.804}{400.021}{\rmfamily\raggedright}{9.96}{12.00}{%
    By registering an object instance of a published class. Upon registration of an object instance, the%
  }
  \HLAFixedBlock{121.978}{295.804}{400.022}{\rmfamily\raggedright}{9.96}{12.00}{%
    registering joined federate shall become the owner of all instance attributes of that object instance%
  }
  \HLAFixedBlock{121.978}{307.804}{400.022}{\rmfamily\raggedright}{9.96}{12.00}{%
    for which the joined federate is publishing the corresponding class attributes at the registered class%
  }
  \HLAFixedBlock{121.978}{319.804}{400.022}{\rmfamily\raggedright}{9.96}{12.00}{%
    of the object instance.%
  }
  \HLAFixedBlock{100.019}{334.803}{421.981}{\rmfamily\raggedright}{9.96}{12.00}{%
    ---%
  }
  \HLAFixedBlock{121.978}{334.803}{400.022}{\rmfamily\raggedright}{9.96}{12.00}{%
    By using ownership management services to acquire instance attributes of object instances. The%
  }
  \HLAFixedBlock{121.979}{346.803}{400.021}{\rmfamily\raggedright}{9.96}{12.00}{%
    joined federate may acquire only the instance attributes for which the joined federate is publishing%
  }
  \HLAFixedBlock{121.979}{358.803}{400.021}{\rmfamily\raggedright}{9.96}{12.00}{%
    the corresponding class attributes at the known class of the specified object instance.%
  }
  \HLAFixedBlock{90.000}{382.803}{432.000}{\rmfamily\raggedright}{9.96}{12.00}{%
    Each use of this service shall add to the publications specified to the RTI in previous service invocations for%
  }
  \HLAFixedBlock{90.000}{394.803}{432.000}{\rmfamily\raggedright}{9.96}{12.00}{%
    the same object class. Invoking this service with an empty set of class attributes shall be equivalent to adding%
  }
  \HLAFixedBlock{90.000}{406.802}{432.000}{\rmfamily\raggedright}{9.96}{12.00}{%
    no publications for the object class.%
  }
