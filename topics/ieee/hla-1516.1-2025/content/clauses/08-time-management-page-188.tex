    \textbf{8.2 }\textbf{\emph{Enable Time Regulation}}\textbf{ service}%
  }
  \HLAFixedBlock{90.000}{406.806}{432.000}{\rmfamily\raggedright}{9.96}{12.00}{%
    The \emph{Enable Time Regulation} service shall enable time-regulation for the joined federate invoking the service%
  }
  \HLAFixedBlock{90.000}{418.805}{432.000}{\rmfamily\raggedright}{9.96}{12.00}{%
    and thereby enable the joined federate to send TSO messages. The joined federate shall request that its%
  }
  \HLAFixedBlock{90.000}{430.805}{432.000}{\rmfamily\raggedright}{9.96}{12.00}{%
    lookahead be set to the specified value. The RTI shall indicate the logical time assigned to the joined%
  }
  \HLAFixedBlock{90.000}{442.805}{432.000}{\rmfamily\raggedright}{9.96}{12.00}{%
    federate through the \emph{Time Regulation Enabled \textdagger{}} service. The logical time provided when time-regulation is%
  }
  \HLAFixedBlock{90.000}{454.805}{432.000}{\rmfamily\raggedright}{9.96}{12.00}{%
    enabled shall be the smallest possible logical time that is greater than or equal to the joined federate’s current%
  }
  \HLAFixedBlock{90.000}{466.805}{432.000}{\rmfamily\raggedright}{9.96}{12.00}{%
    logical time and for which all other constraints necessary to ensure TSO message delivery are satisfied. In%
  }
  \HLAFixedBlock{90.000}{478.805}{432.000}{\rmfamily\raggedright}{9.96}{12.00}{%
    other words, in general, the logical time that the joined federate will be given (plus the requested lookahead)%
  }
  \HLAFixedBlock{90.000}{490.804}{432.000}{\rmfamily\raggedright}{9.96}{12.00}{%
    will always be greater than or equal to the maximum logical time of all time-constrained joined federates%
  }
  \HLAFixedBlock{89.999}{502.804}{432.001}{\rmfamily\raggedright}{9.96}{12.00}{%
    (with the possibility of being of equal value depending on what form of time advancement was used by each%
  }
  \HLAFixedBlock{89.998}{514.804}{432.002}{\rmfamily\raggedright}{9.96}{12.00}{%
    time-constrained joined federate). %
  }
  \HLAFixedBlock{89.998}{538.804}{432.002}{\rmfamily\raggedright}{9.96}{12.00}{%
    Upon the RTI’s invocation of the corresponding \emph{Time Regulation Enabled \textdagger{}} service, the invoking joined%
  }
  \HLAFixedBlock{89.998}{550.803}{432.002}{\rmfamily\raggedright}{9.96}{12.00}{%
    federate may begin sending TSO messages that have a timestamp greater than or equal to the joined%
  }
  \HLAFixedBlock{89.998}{562.803}{432.002}{\rmfamily\raggedright}{9.96}{12.00}{%
