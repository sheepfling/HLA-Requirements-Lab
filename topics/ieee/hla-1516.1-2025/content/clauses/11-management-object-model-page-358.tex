    \textbf{12.9 Dynamic link compatibility}%
  }
  \HLAFixedBlock{90.000}{244.806}{514.000}{\rmfamily\raggedright}{9.96}{11.16}{%
    The Application Programmer Interfaces (API) defined in this specification were designed to meet the%
  }
  \HLAFixedBlock{90.000}{256.805}{514.000}{\rmfamily\raggedright}{9.96}{11.16}{%
    purpose and objectives for dynamic link compatibility (DLC) of RTIs. In general, DLC is the ability to%
  }
  \HLAFixedBlock{90.000}{268.805}{514.000}{\rmfamily\raggedright}{9.96}{11.16}{%
    compile federate code that uses the RTI API such that RTI implementation libraries can be switchable at run-%
  }
  \HLAFixedBlock{90.000}{280.805}{514.000}{\rmfamily\raggedright}{9.96}{11.16}{%
    time without having to recompile the federate code. The precise details of dynamic link compatibility are%
  }
  \HLAFixedBlock{90.000}{292.805}{514.000}{\rmfamily\raggedright}{9.96}{11.16}{%
    language specific and are described in detail in the appropriate language sections.%
  }
