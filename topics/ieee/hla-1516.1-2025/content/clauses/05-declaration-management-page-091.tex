  \HLAFixedBlock{90.000}{364.806}{432.000}{\rmfamily\raggedright}{9.96}{12.00}{%
    The \emph{Unpublish Object Class Attributes} service can be used in multiple ways. First, it could be used to%
  }
  \HLAFixedBlock{90.000}{376.805}{432.000}{\rmfamily\raggedright}{9.96}{12.00}{%
    unpublish a whole object class and thereby inform the RTI that the joined federate shall no longer be capable%
  }
  \HLAFixedBlock{90.000}{388.805}{432.000}{\rmfamily\raggedright}{9.96}{12.00}{%
    of registering object instances of the specified object class. Second, it could be used to unpublish specific%
  }
  \HLAFixedBlock{90.000}{400.805}{432.000}{\rmfamily\raggedright}{9.96}{12.00}{%
    class attributes and thereby inform the RTI that the joined federate shall no longer be capable of owning%
  }
  \HLAFixedBlock{90.000}{412.805}{432.000}{\rmfamily\raggedright}{9.96}{12.00}{%
    instance attributes that correspond to the unpublished class attributes.%
  }
  \HLAFixedBlock{90.000}{436.805}{432.000}{\rmfamily\raggedright}{9.96}{12.00}{%
    If the optional set of attributes designators argument is supplied, only those class attributes shall be%
  }
  \HLAFixedBlock{90.000}{448.804}{432.000}{\rmfamily\raggedright}{9.96}{12.00}{%
    unpublished for the joined federate. Otherwise, all published class attributes of the specified class shall be%
  }
  \HLAFixedBlock{90.000}{460.804}{432.000}{\rmfamily\raggedright}{9.96}{12.00}{%
    unpublished for the joined federate. Invoking this service with an empty set of class attributes shall be%
  }
  \HLAFixedBlock{90.000}{472.804}{432.000}{\rmfamily\raggedright}{9.96}{12.00}{%
    equivalent to removing no publications for the object class.%
  }
  \HLAFixedBlock{90.000}{496.804}{432.000}{\rmfamily\raggedright}{9.96}{12.00}{%
    The joined federate shall lose ownership of all owned instance attributes whose corresponding class%
  }
  \HLAFixedBlock{90.000}{508.803}{432.000}{\rmfamily\raggedright}{9.96}{12.00}{%
    attributes are unpublished by the service invocation; in other words, the joined federate shall no longer be%
  }
  \HLAFixedBlock{90.000}{520.803}{432.000}{\rmfamily\raggedright}{9.96}{12.00}{%
    able to update such instance attributes.%
  }
