  \HLAFixedBlock{90.000}{126.786}{514.000}{\rmfamily\raggedright}{9.96}{11.16}{%

  }
  \HLAFixedBlock{90.000}{138.785}{514.000}{\rmfamily\raggedright}{9.96}{11.16}{%

  }
  \HLAFixedBlock{90.000}{150.785}{514.000}{\rmfamily\raggedright}{9.96}{11.16}{%

  }
  \HLAFixedBlock{90.000}{162.785}{514.000}{\rmfamily\raggedright}{9.96}{11.16}{%
    strategy chosen for advancing federation time is an extremely important consideration in the design of a%
  }
  \HLAFixedBlock{90.000}{174.785}{514.000}{\rmfamily\raggedright}{9.96}{11.16}{%
    simulation, the format of how federation time is represented is of equal importance.%
  }
  \HLAFixedBlock{90.000}{198.785}{514.000}{\rmfamily\raggedright}{9.96}{11.16}{%
    It is very important for all federation members to agree upon a common set of key federation time%
  }
  \HLAFixedBlock{90.000}{210.784}{514.000}{\rmfamily\raggedright}{9.96}{11.16}{%
    characteristics that apply across the full federation. In addition to defining certain characteristics of the time%
  }
  \HLAFixedBlock{90.001}{222.784}{513.999}{\rmfamily\raggedright}{9.96}{11.16}{%
    axis, it is also important to define the lookahead characteristics of both federates and federations. It is%
  }
  \HLAFixedBlock{90.001}{234.784}{513.999}{\rmfamily\raggedright}{9.96}{11.16}{%
    important to recognize that there are semantic differences between the way federation time is represented for%
  }
  \HLAFixedBlock{90.001}{246.784}{513.999}{\rmfamily\raggedright}{9.96}{11.16}{%
    the purpose of advancing federation time versus calculating lookahead. When advancing federation time,%
  }
  \HLAFixedBlock{90.001}{258.784}{513.999}{\rmfamily\raggedright}{9.96}{11.16}{%
    federation time can be considered to be an absolute value on a federation timeline, and thus federation time%
  }
  \HLAFixedBlock{90.001}{270.783}{513.999}{\rmfamily\raggedright}{9.96}{11.16}{%
    comparisons can be drawn to determine if one federation time value is greater than another. Lookahead, in%
  }
  \HLAFixedBlock{90.000}{282.783}{514.000}{\rmfamily\raggedright}{9.96}{11.16}{%
    contrast, represents a duration of federation time, which can be added to absolute federation time values but%
  }
