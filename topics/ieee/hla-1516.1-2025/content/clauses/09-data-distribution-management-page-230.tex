  }
  \HLAFixedBlock{90.001}{412.805}{431.999}{\rmfamily\raggedright}{9.96}{12.00}{%
    attributes of a specific object instance.%
  }
  \HLAFixedBlock{90.001}{436.805}{431.999}{\rmfamily\raggedright}{9.96}{12.00}{%
    A joined federate that has associated regions with an instance attribute for update should maintain the region%
  }
  \HLAFixedBlock{90.001}{448.805}{431.999}{\rmfamily\raggedright}{9.96}{12.00}{%
    dimensions such that they adequately and correctly bound the portion of space in which communication of%
  }
  \HLAFixedBlock{90.001}{460.805}{431.999}{\rmfamily\raggedright}{9.96}{12.00}{%
    updates to the instance attribute are relevant at the wall-clock time when an \emph{Update Attribute Values} service%
  }
  \HLAFixedBlock{90.001}{472.805}{431.999}{\rmfamily\raggedright}{9.96}{12.00}{%
    is invoked.%
  }
  \HLAFixedBlock{90.001}{496.804}{431.999}{\rmfamily\raggedright}{9.96}{12.00}{%
    The association shall be used by the \emph{Update Attribute Values} service to route data to subscribers whose%
  }
  \HLAFixedBlock{90.001}{508.804}{431.999}{\rmfamily\raggedright}{9.96}{12.00}{%
    subscription region sets overlap the specified update region set. If an instance attribute is associated with the%
  }
  \HLAFixedBlock{90.001}{520.804}{431.999}{\rmfamily\raggedright}{9.96}{12.00}{%
    default region, then invocation of the \emph{Associate Regions For Updates} service shall remove the association of%
  }
  \HLAFixedBlock{90.002}{532.804}{431.998}{\rmfamily\raggedright}{9.96}{12.00}{%
    that instance attribute with the default region and add the association of that instance attribute with the%
  }
  \HLAFixedBlock{90.002}{544.803}{431.998}{\rmfamily\raggedright}{9.96}{12.00}{%
    specified region. If an instance attribute is not associated with the default region, then invocation of the%
  }
  \HLAFixedBlock{90.002}{556.803}{431.998}{\rmfamily\raggedright}{9.96}{12.00}{%
    \emph{Associate Regions For Updates} service shall add the specified regions to the set of associations of the%
  }
  \HLAFixedBlock{90.003}{568.803}{431.997}{\rmfamily\raggedright}{9.96}{12.00}{%
    specified instance attribute. No changes shall be made to the association set if the specified regions are%
  }
  \HLAFixedBlock{90.003}{580.803}{431.997}{\rmfamily\raggedright}{9.96}{12.00}{%
    already in the set of associations of the specified instance attributes.%
  }
  \HLAFixedBlock{90.003}{604.802}{431.997}{\rmfamily\raggedright}{9.96}{12.00}{%
