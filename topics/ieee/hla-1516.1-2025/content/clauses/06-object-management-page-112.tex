    6.1.13 Sending updates with update rate reduction%
  }
  \HLAFixedBlock{89.998}{405.780}{432.002}{\rmfamily\raggedright}{9.96}{12.00}{%
    The RTI shall not provide an update rate to a joined federate that exceeds the subscribed update rate. It shall%
  }
  \HLAFixedBlock{89.998}{417.780}{432.002}{\rmfamily\raggedright}{9.96}{12.00}{%
    not, however, deliver any more updates than what is provided by the owning joined federate. In other words,%
  }
  \HLAFixedBlock{89.998}{429.780}{432.002}{\rmfamily\raggedright}{9.96}{12.00}{%
    any minimum update rate shall not be guaranteed. In case a joined federate has subscribed with an update%
  }
  \HLAFixedBlock{89.998}{441.780}{432.002}{\rmfamily\raggedright}{9.96}{12.00}{%
    rate other than the default update rate, the RTI shall handle this situation as follows:%
  }
  \HLAFixedBlock{100.018}{456.780}{421.982}{\rmfamily\raggedright}{9.96}{12.00}{%
    a)%
  }
  \HLAFixedBlock{121.972}{456.780}{400.028}{\rmfamily\raggedright}{9.96}{12.00}{%
    For attributes with best-effort transportation, messages shall not be delivered to a joined federate%
  }
  \HLAFixedBlock{121.978}{468.779}{400.022}{\rmfamily\raggedright}{9.96}{12.00}{%
    with an update rate higher than the subscribed update rate. Any messages in excess of this rate shall%
  }
  \HLAFixedBlock{121.977}{480.779}{400.023}{\rmfamily\raggedright}{9.96}{12.00}{%
    be dropped. Given a maximum update rate of \emph{x} Hz and given that a message has been delivered at%
  }
  \HLAFixedBlock{121.977}{492.779}{400.023}{\rmfamily\raggedright}{9.96}{12.00}{%
    wall-clock time \emph{t}, no message shall be delivered before \emph{t} + (1 / \emph{x}).%
  }
  \HLAFixedBlock{100.016}{507.779}{421.984}{\rmfamily\raggedright}{9.96}{12.00}{%
    b)%
  }
  \HLAFixedBlock{121.976}{507.779}{400.024}{\rmfamily\raggedright}{9.96}{12.00}{%
    For attributes with reliable transportation, no messages shall be dropped.%
  }
  \HLAFixedBlock{89.996}{531.778}{432.004}{\rmfamily\raggedright}{9.96}{12.00}{%
    In case the attribute relevancy advisory switch is enabled, the owning joined federate shall be notified of the%
  }
  \HLAFixedBlock{89.996}{543.778}{432.004}{\rmfamily\raggedright}{9.96}{12.00}{%
    maximum actively subscribed update rate as part of the \emph{Turn Updates On For Object Instance \textdagger{}} service%

  \HLAFixedBlock{89.996}{555.778}{432.004}{\rmfamily\raggedright}{9.96}{12.00}{%

  }
  \HLAFixedBlock{89.996}{567.778}{432.004}{\rmfamily\raggedright}{9.96}{12.00}{%
    joined federates whenever the maximum actively subscribed update rate in the federation execution changes.%
