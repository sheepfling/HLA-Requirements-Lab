# HLA RTI compliance requirements

This is the implementation-facing requirements publication. It is independent
of the faithful and hierarchy-reconstruction PDFs: it loads the semantic
corpus directly and emits a readable evidence contract, JSON manifest, graph,
and normalized CSV projections under ignored `output/compliance/`.

```console
hla-lab publish hla-rti-compliance-requirements-2025
```

Planned mappings are planning seams, not proof of RTI conformance. Concrete
source and test evidence is the separate M30 boundary.
