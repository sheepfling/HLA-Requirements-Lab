# Requirements Lab Design System v0.1 style specimen

This is the visual unit-test publication for the shared Requirements Lab
publishing system. It demonstrates the first house components before a full
1516.2 modern-profile migration:

- typography roles and technical-token rendering;
- clause and subclause hierarchy;
- notes, examples, rationale, and Lab notes;
- reference, registry, dense, landscape, and continued tables;
- hierarchy views, equations, byte layouts, code/XML, and diagrams;
- cross-reference/navigation intent; and
- provenance and QA contracts.

Build with:

```console
python build.py build
```
